Wanderlust – Airbnb-like Full Stack Web Application
Designed and developed a feature-rich travel accommodation platform allowing users to list properties, upload images, search by location, filter by categories, and leave reviews. Implemented secure user authentication & authorization, RESTful APIs, cloud-based image storage, and interactive maps for better user experience.
Optimized backend with MongoDB and Mongoose, handled error management using middleware, and followed MVC architecture for clean code structure.
Tech Stack: Node.js, Express.js, MongoDB, Mongoose, EJS, Bootstrap, Cloudinary, Leaflet, Mapbox, Render
